## Distinctions
上 "previous" and 下 "next" here are the same temporal-metaphor pair as
上次/下次 and 上个月/下个月 — not literally "up/down." The full set is 上周 /
这周 "this week" / 下周; 周 and 星期 are interchangeable, so 上周 = 上星期 and
下周 = 下星期. Do not confuse this axis with 上课/下课 (start/finish a class
session), which uses the same 上/下 characters on a different axis entirely.

## Corpus evidence
Lexicographic (L): 现汉 defines each against the other as the previous/next
member of the weekly cycle.
Reviewed (R): both word files name the same three-way set (上周/这周/下周).
