## Distinctions
Both attach after a stated boundary (三米以外 "beyond three metres" / 三米以内
"within three metres") — the shared 以 marks the reference point, and 外/内
"outside/inside" set the direction. 以外 additionally has the idiomatic
除了…以外 construction ("apart from…"), a use 以内 does not share. This is a
spatial/quantitative range pair, distinct from the temporal 以后/以前
(after/before).

## Corpus evidence
Lexicographic (L): 现汉 defines each as the outside/inside half of a stated
range, sharing the same 以 reference-point marker.
Reviewed (R): both word files independently analyse 以 the same way and
oppose 外/内 directly.
