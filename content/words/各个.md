## Why this combination

各 ("each, every," as in 各国, "every country") takes 个 (the generic
measure word) as a fused pair, emphasizing individual members of a set
one by one rather than the set as a whole.

## Notes

各个 typically precedes a noun or, before a verb, marks the action as
done to each one separately (各个击破, "to defeat one by one") — a set
phrase distinct from plain 各, which can stand alone or with other
classifiers (各位, 各国).
