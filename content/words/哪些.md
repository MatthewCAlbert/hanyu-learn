## Why this combination
Interrogative 哪 "which" + the vague-plural 些 → "which several," asking for a
subset. Completes the 这些 / 那些 / 哪些 set (see [[这些]]). 些 supplies the
plural, so no measure word.

## Notes
哪个 asks for one; 哪些 asks for more than one. 哪 *nǎ* vs. 那 *nà* differ only
in tone.
