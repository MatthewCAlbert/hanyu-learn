## Why this combination
A near-synonym compound: 设 ("to establish, to set up," covered in this
app's entry for 设置) and 施 ("to carry out, to put into practice,"
covered elsewhere in this app) both independently name putting something
in place for use. Pairing them gives the standard word for physical
facilities set up to serve a purpose.

## Notes
公共设施 ("public facilities") and 基础设施 ("infrastructure," lit.
"foundational facilities") both build on this pair's core "equipment set
up for use" sense.
