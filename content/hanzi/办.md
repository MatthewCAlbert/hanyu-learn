## Etymology
Simplified from 辦. The full graph is 力 "effort" between two 辛 (blades /
implements of judgement), which carried the sound (辡 *biàn*). Shuowen: 致力也
"to apply effort." Simplification keeps 力 and shrinks the flanking 辛 to two
strokes, so the phonetic is gone.

## Mnemonic
Effort 力 applied to a matter: to get it done.

## Notes
Senses: handle / manage (办事, 办理, 举办), set up / run (办学, 创办), buy in
(办年货), punish (法办, 惩办). 办公室 "office."
