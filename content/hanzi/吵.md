## Etymology
Pictophonetic. 口 (mouth) supplies the meaning; 少 *shǎo* supplies the
sound. Confidence is medium for the same reason as 哈 and 娘 elsewhere in
this dataset: 吵 postdates Shuowen Jiezi, so there is no Han-dynasty
analysis to cite — only the character's own, still-legible modern
construction, first attested in later rhyme dictionaries with the related
sense "to disturb, to make a racket."

## Mnemonic
Even a few 少 words 口, said the wrong way, can start a fight.

## Notes
吵 covers both the noise itself (吵闹, noisy) and the argument that
produces it (吵架, 争吵) — an unbroken line from raised voices to open
conflict.
