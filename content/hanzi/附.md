## Etymology
Pictophonetic: the semantic component started as 土 (earth, in the older
variant 坿) and was later written with 阝 (mound) instead — both point to
"a mound built up, added on." 付 *fù* supplies the sound, an exact match.

"To add on to" (益) generalized to "to attach to, to be adjacent to"
(附近, covered elsewhere in this app; 附件, an attachment).

## Mnemonic
Earth 阝 heaped up and paid in 付 (added on) beside the main mound: to
"附," attach.

## Notes
附近 ("nearby," lit. "attached-near") and 附件 ("an attachment," e.g. to an
email) both build directly on this "added on beside" core sense.
