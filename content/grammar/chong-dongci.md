## Pattern
When a verb has both an object and a complement, the verb repeats around the object: *S + V + O + V + Complement*. 打篮球打得很好 (not *打篮球得很好) attaches [[grammar:de-complement]]'s 得很好 to a second copy of 打, since 得 cannot follow the object directly.

## Usage
The same fix applies to a plain [[grammar:result-complement-2]]: 走路走累了 "walked until tired" — 走累了 alone would drop the object 路. Only the second V carries the complement; the first V+O can be shortened or dropped once context makes the activity clear: 篮球打得很好.

## Notes
This is a repair for a word-order collision, not a new meaning — 打篮球打得好 and (if it were grammatical) *打篮球得好 would mean the same thing; only the first is sayable.
