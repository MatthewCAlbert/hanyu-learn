## Pattern
To describe what exists somewhere in a particular arrangement, open with the place, then a verb+[[grammar:zhe-durative]], then the thing: *Place + V着 + Noun*. This is more specific than plain [[grammar:you-existence]] (桌子上有一本书), which only states that something is there without saying how.

## Usage
The noun after V着 is new information and usually indefinite (一本书, 一位老师), the same way English "a book" introduces something for the first time. Common verbs here: 放着, 站着, 坐着, 挂着.

## Notes
Word order is fixed — the place always comes first in this pattern, unlike a plain subject–verb sentence.
